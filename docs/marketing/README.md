# OpenWhisper Marketing Workspace

Legacy campaign exports are intentionally excluded from the productized repository. New public assets must be generated from the current installed OpenWhisper build and must match the claims approved in the macOS productization plan.

Before publishing any asset:

- use the OpenWhisper name and current version only;
- show the real `/Applications/OpenWhisper.app` build;
- state that the default account route depends on upstream availability;
- do not imply OpenAI affiliation, sponsorship, unlimited usage, or a stable public API;
- do not publish screenshots that contain tokens, transcripts, account identifiers, or unrelated desktop data.
