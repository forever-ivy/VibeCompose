OpenWhisper 连接用户自己的 ChatGPT 账户，把录音、转写、术语保护和安全回填压缩成一个 macOS 原生输入动作。无法确认可编辑目标时，结果保留在剪贴板。

single-trigger workflow

不切应用，不打开聊天窗口。

OpenWhisper 的核心不是“多一个录音工具”，而是把语音变成当前输入框的一种输入方式。

01 光标聚焦真实可编辑位置
02 F5开始录音
03 F5停止并转写
04 处理术语对齐与可选润色
05 输出安全回填或剪贴板

mac first

先把 macOS 版本做成可信赖的日常工具。

第一阶段只聚焦菜单栏、快捷键、权限、转写、回填、历史与术语管理，不同时扩张 Windows、iOS 或会议机器人。

A

原生交互

AppKit + SwiftUI、系统菜单、Settings、HUD、键盘与辅助功能语义。

B

安全输入

每次粘贴前重新确认目标；无法证明安全时只保留剪贴板。

C

专业工作流

中英混输、技术术语、应用模式、历史恢复与可控数据留存。

release gates

Alpha 可以试，商业发布必须过门禁。

默认账户路径依赖上游可用性，不是稳定公开 API。OpenWhisper 不暗示 OpenAI 隶属、赞助或背书，也不承诺无限用量。

安全

Token 目标白名单、Recovery 路径约束、刷新竞态、安全粘贴。

隐私

成功音频删除、历史留存策略、删除全部数据、敏感应用策略。

发布

Developer ID、Hardened Runtime、公证、staple、固定哈希和更新签名。

产品

原生 onboarding、可访问性、错误恢复、匿名且最小化的产品指标。
