# VibeCompose 0.1.0 Alpha

VibeCompose 0.1.0 是当前产品身份下的首个 macOS 私有 Alpha，不是生产版。

## 主要能力

- 可自定义的单触发听写快捷键，默认仍为 F5；
- Refined HUD、AI Activity Glow 和 Hidden 三种反馈模式；
- 声明式 Skills、本地 Validator 与安全 Direct 回退；
- 经用户授权的选中文本上下文、Diff Preview 和精确替换校验；
- Writing Styles 与分层术语包；
- 本地、不可执行的 `.vibecomposeskill` 导入、审查、回滚、禁用、卸载、
  Inspector 和 Golden tests；
- 明确区分“已确认插入 / 已发送粘贴 / 仅复制”；
- 隐私控制、有界留存、诊断导出和删除全部数据；
- Sparkle、签名能力策略、公证与发布门禁基础。

## 重要限制

- 默认 ChatGPT 路径依赖未公开的上游行为，不是稳定公开 API 或 SLA；
- 当前 Alpha 不是面向公众分发的 Developer ID 公证版本；
- 生产更新托管、品牌清查和公开支持渠道尚未完成；
- 当前工作名称存在同品类名称冲突，仓库中的品牌清查已将公开发布标记为
  blocked。

## 验证

真实验证路径只能使用 `/Applications/VibeCompose.app`。本地开发可使用
ad-hoc 签名，但它不适合公开分发，也不能提供稳定的 macOS 权限身份。

英文发布说明见 [`v0.1.0.md`](v0.1.0.md)。
