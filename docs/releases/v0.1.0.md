# VibeWhisper 0.1.0 Alpha

VibeWhisper 0.1.0 is the first private macOS alpha under the current product
identity. It is not a production release.

## Highlights

- configurable single-trigger dictation shortcut, defaulting to F5;
- Refined HUD, AI Activity Glow, and Hidden feedback modes;
- declarative Skills with local validation and safe Direct fallback;
- authorized selected-text context with Diff Preview and exact replacement
  verification;
- Writing Styles and layered terminology packs;
- local, non-executable `.vibewhisperskill` import with review, rollback,
  disable, uninstall, Inspector, and Golden tests;
- conservative verified insertion, paste-sent, and clipboard-only outcomes;
- privacy controls, bounded retention, diagnostics export, and Delete All Data;
- Sparkle, signed capability-policy, notarization, and
  release-gate foundations.

## Important limitations

- The default ChatGPT route depends on undocumented upstream behavior and is
  not a stable public API or service-level commitment.
- This alpha is not Developer ID notarized for public distribution.
- Production update hosting, brand clearance, and public support channels are
  not complete.
- The current working name is blocked from public launch by a same-category
  product-name conflict documented in the repository.

## Verification

Use only the installed path `/Applications/VibeWhisper.app`. Local development
builds may use ad-hoc signing, which is not suitable for public distribution
or stable macOS permission identity.
