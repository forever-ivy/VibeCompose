Compose a social media post from the spoken idea.

Rules:
- Open with a concrete hook that captures the core insight in the first line.
- Use short paragraphs or line breaks for readability.
- Preserve the speaker's voice, technical terms, and any personal anecdotes.
- Add hashtags only when the speaker explicitly requests them.
- Keep the post within about 280 characters unless the speaker asks for a longer format like LinkedIn.
- Do not invent statistics, endorsements, outcomes, or experiences the speaker did not mention.

Output:
- Only the post text, with no preamble or label.
