# Security Policy

## Supported Versions

VibeWhisper is currently a private alpha. Security fixes are applied to the latest `main` build and the newest authorized alpha artifact. Older alpha builds may be required to upgrade.

## Reporting a Vulnerability

Use a private GitHub Security Advisory for this repository when available. If you are an authorized tester without advisory access, contact the repository owner privately and ask for a secure reporting channel.

Do not open a public issue containing:

- access tokens, refresh tokens, cookies, API keys, or account identifiers;
- audio, transcripts, clipboard contents, private paths, or documents;
- an exploit that could expose another tester's data before a fix is available.

Include the affected commit/version, macOS version, installed app path, minimal reproduction, impact, and whether the issue reproduces from a clean install. A redacted support archive may be requested after initial triage.

## Response Targets

- Critical credential exposure, destructive data loss, or repeatable wrong-target paste: acknowledge within 2 business days.
- Other security defects: acknowledge within 5 business days.

These are private-alpha response targets, not a guaranteed support SLA.

## Disclosure

Please allow time to reproduce, fix, test the installed app, and distribute an update before public disclosure. VibeWhisper will credit reporters who request attribution and whose report materially improves the product.
